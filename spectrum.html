Which operator is being diagonalized?

Primitive-scalar radial reduction

The constrained singlet is parameterized by one radial function v(τ), with the second component fixed by the ∂-closedness condition.

\[q[v]=\cosh(\tau)\,v+\frac12\sinh(\tau)\,v'\]
\[D_Pv=v''+4\coth(\tau)\,v'+4v\]

Manuscript Chapters 2–3, especially Eqs. (2.4)–(2.9) and (3.2)–(3.8).

One-sided variational eigenproblem

\[c^{2}[v]=\frac{\frac14\int_0^\infty p(\tau)\sinh^{2}(\tau)\,|D_Pv|^{2}\,d\tau}{\int_0^\infty W(\tau)\bigl(|v|^{2}+2|q[v]|^{2}\bigr)\,d\tau}\]
\[\begin{aligned}p(\tau)&=(\sinh 2\tau-2\tau)^{2/3},\\ W(\tau)&=\sinh^{2}(\tau)\frac{h(\tau)}{h(0)}\end{aligned}\]

The weight follows \(-\frac{d}{d\tau}(p(\tau)h'(\tau))=S(u(\tau))\), with regularity at \(\tau=0\) and decay at infinity.

Zero mode: the analytic A-period zero mode has DPvA = 0 and is excluded by fixing the A-period. With finite-radius numerical boundary conditions it appears as a small near-zero eigenvalue, not as a physical glueball state.

Lefschetz tower — \(0^{-+}\) glueballs

A second, distinct scalar-singlet block; interpreted here as the pseudoscalar \(0^{-+}\) family.

Manuscript Chapters 4–5

State assignment in the manuscript: The primitive sector represents \(0^{++}\), while the Lefschetz sector represents \(0^{-+}\). The latter is governed by its own Sturm–Liouville problem, not by the primitive radial operator. This is the assignment used for the comparisons below.

\[ \begin{aligned} D_Lf&=f'+\coth(\tau)f,\\ Q_L[f]&=\frac12\int_0^\infty p\left(|D_Lf|^2+\frac12\left(\frac{p'}p\right)^2|f|^2\right)d\tau,\\ N_L[f]&=\int_0^\infty W(\tau)|f|^2\,d\tau,\qquad c_n^2=\frac{Q_L[f_n]}{N_L[f_n]}. \end{aligned} \]

Direct cross-channel test

The state assignment is explicit: in this work the Lefschetz ground mode is the \(0^{-+}\) glueball, while the primitive ground mode is the \(0^{++}\) glueball. Using their reported squared eigenvalues gives

\[\frac{M_{0^{-+}}}{M_{0^{++}}}=\sqrt{\frac{c_{L,0}^{\,2}}{c_{P,0}^{\,2}}}=\sqrt{\frac{0.9981}{0.4220071}}\]

Run the numerical calculation

Download Python script

The script constructs the radial RG source, integrates the Stenzel weight, assembles the manuscript's quadratic forms using cubic B-splines and Gaussian quadrature, and solves the generalized eigenvalue problem. It does not just read back the table above.

python -m pip install -r requirements.txt
python scripts/solve_primitive.py --tau-max 27 --intervals 220 --csv scalar_galerkin_results.csv
python scripts/solve_lefschetz.py --tau-max 16 --intervals 150 --csv scalar_lefschetz_results.csv
python scripts/plot_comparison.py --out scalar_spectrum_comparison.png

A test run at τmax = 27 with 220 spline intervals gave h(0) = 0.134078555 and physical squared eigenvalues ≈ 0.422223, 1.035770, 1.874805, 2.936319, 4.219148, 5.722961. These are numerical approximations. Increase τmax and the spline resolution to test convergence. The near-zero finite-domain mode must be excluded.
