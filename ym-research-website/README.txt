YANG–MILLS RESEARCH WEBSITE — QUICK START
========================================

The file index.html is a complete one-page research website. No programming or paid hosting is required.

1. Make a GitHub account at https://github.com (if you do not have one).
2. Create a PUBLIC repository named YOUR-USERNAME.github.io, substituting your exact username.
3. On the repository's Code tab, choose Add file > Upload files.
4. Upload index.html from this folder. Click Commit changes.
5. On GitHub, open Settings > Pages. Choose 'Deploy from a branch'. Select 'main' and '/ (root)', then Save.
6. Visit https://YOUR-USERNAME.github.io after GitHub Pages publishes it.
7. Upload your manuscript PDF under the exact filename manuscript.pdf into the same repository root.
   Alternatively, upload it to Zenodo and replace 'manuscript.pdf' links in index.html with the published Zenodo URL.
8. Edit the page using GitHub's pencil (Edit) icon, then commit changes. Changes will publish automatically.

BEFORE PUBLISHING
- Check that the paper title, authorship, summary, date and status text are correct.
- Do not claim independent peer review or an accepted proof if neither has happened.
- If sharing source code, upload it separately or link a repository.
- If you want a DOI, create a Zenodo record at https://zenodo.org and link its DOI from the page.

As of preparation, this template contains no actual manuscript.pdf file or Zenodo DOI. Add your own manuscript before announcing the site.
